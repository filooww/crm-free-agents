// how it works

The approach

Works entirely client-side in an already-authenticated browser session. No backend needed — bypasses VPN/certificate complexity completely.

01 / FIND NOW

Locate current time

Reads the red vertical separator line's left CSS property — no math, exact pixel position of "now".

02 / PARSE ROWS

Extract agent rows

Finds the target group header, slices to that group only, filters out non-agents.

03 / INTERSECT

Check Y + X overlap

For each agent: getBoundingClientRect() for Y-axis row match, style.left + width for X-axis time match.

04 / VIRTUAL SCROLL

Handle virtualization

Pre-computes scroll positions by accumulating offsetHeight — because offsetTop is always 0 in virtual lists.

// Step 1: Find the red "now" line → exact pixel position
const sep = document.querySelector('.scheduler_default_separator');
const nowPx = sep ? parseInt(sep.style.left) : 0;

// Step 2: For each agent, check if any event intersects "now"
const results = agentRows.map(agent => {
  const busy = events.some(ev => {
    const evRect = ev.getBoundingClientRect();
    const yMatch = evRect.top < agent.rect.bottom
                && evRect.bottom > agent.rect.top;
    const xMatch = parseInt(ev.style.left) <= nowPx
                && parseInt(ev.style.left)
                 + parseInt(ev.style.width) >= nowPx;
    return yMatch && xMatch;
  });
  return { name: agent.name, busy };
});
