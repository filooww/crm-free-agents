// categories

Four categories, instantly

Each agent is classified by what's happening at the current red time-line, what's coming up in the next 15 minutes, and the colors of their tasks. Background activity (calls, PC maintenance) doesn't count as busy.

✓

Free

Available now with no blocking task starting soon.

◷

Soon busy

Free now, but a blocking task starts within ~15 min.

☕

On break

Break in progress or starting soon, with countdown.

✗

Busy

Actively occupied right now — don't assign new work.

// how it works

The approach

Works entirely client-side in the existing authenticated session — bypassing VPN and client-certificate auth complexity. The bookmarklet is read-only and adds only a floating overlay.

01 / SCROLL & COLLECT

Beat virtual scrolling

Programmatically scrolls the DayPilot container in 400px steps, dispatching scroll events so all rows get rendered, then restores the original position.

02 / FIND GROUP

Slice the target group

Finds the support-agents group header and slices rows until the next group, ignoring managers, team leads, and hotline operators.

03 / FILTER SHIFT

Skip non-working agents

Drops anyone with zero events in a ±1 hour window — days off, ended shifts, not started yet.

04 / CLASSIFY EVENTS

Color + width + border

Maps each task block to "busy" or "free" by RGB color. Disambiguates ambiguous colors by block width. Treats the CRM's orange active-border as a secondary signal.

05 / COMPUTE TIMING

Pixel-accurate countdowns

72px = 1 hour. Distance from the red current-time line gives "starts in ~Xm" or "ends in ~Xm" labels for breaks and incoming tasks.

06 / SCROLL-TO

Click-to-navigate

The → button on each agent re-uses the same programmatic scrolling to jump the CRM directly to that row and highlight it.

// Find the red current-time line
const sep = document.querySelector('.scheduler_default_separator');
const nowPx = parseInt(sep.style.left);

// For each event, classify by color (with width disambiguation)
function classifyEvent(color, width) {
  if (color === BREAK_COLOR) return 'break';
  if (BUSY_COLORS.includes(color)) return 'busy';
  // Navy = PC maintenance (free) if wide, hotline (busy) if narrow
  if (color === NAVY) return width <= 50 ? 'busy' : null;
  return null;
}

// Scroll the virtual list to render all rows
for (let pos = 0; pos <= maxScroll; pos += 400) {
  rowHeaderScroll.scrollTop = pos;
  rowHeaderScroll.dispatchEvent(new Event('scroll', { bubbles: true }));
  await new Promise(r => setTimeout(r, 400));
  // ... collect rows + events visible at this scroll position
}
